# 활동 지도 — 활동·협력·목적·순환을 탐색하는 도구

> 개인과 조직이 해온 일, 진행 중인 일, 하려는 일을 기록하고, 누가 어떤 역할로 참여하며 무엇을 주고받는지, 어떤 변화와 목적에 기여하는지를 여러 관점에서 탐색하는 시각적 사고 도구.

가칭은 ‘활동 지도’로 한다. 활동과 관계를 한 번 기록하고, 시간·협력·목적·순환이라는 질문에 따라 서로 다른 지도로 보여준다.

## 1. 도구의 목적

일정이나 개별 과제를 관리하는 것에서 나아가, 여러 활동이 이루는 전체 구조를 이해하고 다음 선택을 돕는다.

- 과거의 경험이 현재 활동과 미래 구상으로 어떻게 이어지는가?
- 누가 어떤 역할을 맡고 있으며, 누구에게 책임과 부담이 집중되는가?
- 활동 사이에서 경험·사람·돈·공간·기술이 어떻게 오가는가?
- 서로 다른 활동은 어떤 변화와 목적에서 만나는가?
- 반복되는 성과와 어려움에는 어떤 순환 구조가 있는가?
- 무엇을 유지·확대·통합·축소하거나 새로 연결하면 좋을까?

개인의 활동을 정리하는 데서 시작할 수 있고, 여러 사람이 참여하는 조직이나 협력 사업에도 적용할 수 있다.

## 2. 기본 개념

도구는 주체·활동·변화와 목적·변화 요인, 그리고 이들 사이의 관계로 구성한다.

| 요소 | 의미 | 예시 |
|---|---|---|
| 주체 | 활동에 참여하는 사람과 단체 | 개인, 공동체IT, 추진위원회, 협력 단체 |
| 활동 | 수행했거나 수행 중이거나 구상 중인 일 | IT학교, IT 지원, 조직 운영, 학습·회복 |
| 변화·목적 | 활동으로 기대하거나 관찰하는 변화와 지향점 | 활용 능력 향상, 디지털 배제 감소 |
| 변화 요인 | 영향의 순환을 분석하는 증감 가능한 요소 | 업무량, 회복 여력, 현장 피드백의 양 |

활동은 큰 사업부터 세부 프로그램까지 포함한다. 예를 들어 ‘IT학교’ 안에 ‘박람회 참여’, 그 안에 ‘진단 프로그램 운영’을 둘 수 있다.

다른 사업에도 쓰이는 활동은 포함 관계를 중복시키기보다 ‘지원한다·활용된다’는 연결로 표현한다.

## 3. 관계가 담는 정보

관계는 단순한 연결선이 아니라, 무엇을 어떻게 주고받거나 변화시키는지에 대한 기록이다.

| 관계 | 연결 대상 | 예시 |
|---|---|---|
| 참여·역할 | 주체 → 활동 | 협력 단체가 IT학교의 참여자를 모집 |
| 포함 | 활동 → 세부 활동 | IT학교에 역량진단 프로그램이 포함 |
| 지원·연계·경합 | 활동 ↔ 활동 | IT 지원 경험이 교육 설계에 활용됨 |
| 기여 | 활동·변화·목적 사이 | 교육이 활용 능력 향상에 기여 |
| 영향 | 변화 요인 → 변화 요인 | 업무량 증가가 회복 여력을 감소시킴 |

협력은 우선 ‘어떤 활동에서 누가 무엇을 맡는가’를 중심으로 기록한다. 별도의 협약이나 소속 자체가 중요하면 주체 사이의 관계도 기록할 수 있다.

참여와 지원 관계에는 필요에 따라 기여 내용을 붙인다.

- 시간·노동
- 돈
- 공간·장비
- 기술·지식
- 사람·접점

수량과 단위는 선택 사항이다. 모든 기여를 금액으로 환산하거나 서로 다른 자원을 하나의 점수로 합치지 않는다.

## 4. 네 가지 보기

| 보기 | 핵심 질문 | 주요 표현 |
|---|---|---|
| 시간 보기 | 어떻게 이어져 왔고, 어디로 이어질까? | 활동의 기간·동시 진행·전환점과 활동 간 연결 |
| 협력 보기 | 누가 어떤 역할로 참여하고 무엇을 제공할까? | 주체·활동·역할·기여 |
| 목적 보기 | 어떤 변화와 가치에 기여할까? | 활동 → 직접적인 변화 → 목적 |
| 순환 보기 | 어떤 영향이 되돌아와 상황을 강화하거나 조절할까? | 변화 요인·영향 방향·지연·되먹임 |

### 시간 보기

간단하게는 ‘해온 일·진행 중인 일·하려는 일’로 배치하고, 날짜가 있으면 실제 시간축 위에 기간을 표시한다.

활동뿐 아니라 참여·역할·지원 관계에도 기간을 둘 수 있다. 이를 통해 같은 사업에서 운영 주체나 역할 분담이 바뀌는 모습도 살펴본다.

시간상 먼저 일어났다는 사실과 원인이 되었다는 해석은 구분한다.

### 협력 보기

활동을 중심에 두고 참여 주체와 역할을 펼치거나, 특정 주체를 중심으로 참여 활동을 모아본다.

역할과 기여를 함께 살펴보며 책임의 집중, 협력의 빈틈, 특정 주체에게 의존하는 부분을 발견하도록 돕는다. 연결 수만으로 실제 업무 부담을 판단하지는 않는다.

### 목적 보기

하나의 활동이 여러 목적에 기여하고, 여러 활동이 하나의 목적에서 만나는 구조를 표현한다.

직접적인 사회적 변화뿐 아니라 운영·재원 확보·역할 분담·개인의 회복처럼 다른 활동을 가능하게 하는 기여도 다룬다.

### 순환 보기

중요한 관계를 골라 ‘늘거나 줄 수 있는 변화 요인’으로 펼친다.

영향 관계에는 같은 방향의 영향(+), 반대 방향의 영향(−), 지연을 표시할 수 있다. 이를 연결해 변화를 키우는 강화 순환과 변화를 억제하거나 조절하는 균형 순환을 살펴본다.

활동이 반복되는 흐름과 인과적 되먹임은 구분한다. 활동 간 연결을 자동으로 인과관계로 바꾸지 않는다.

## 5. 하나의 기록, 여러 관점

예를 들어 ‘IT학교’는 네 보기에 등장하더라도 하나의 활동 기록이다.

| 보기 | IT학교에서 살펴보는 것 |
|---|---|
| 시간 | 어떤 경험에서 출발했고, 무엇으로 이어지는가 |
| 협력 | 누가 기획·운영·교육·모집·재원 확보를 맡는가 |
| 목적 | 누구에게 어떤 변화를 만들고자 하는가 |
| 순환 | 현장 피드백·교육 적합성·활용 경험 등이 어떻게 되먹임되는가 |

활동의 이름과 설명을 수정하면 모든 보기에 반영된다. 화면의 위치·필터·펼침 상태는 보기별로 관리한다.

보기 전환은 입력한 정보를 다른 기준으로 보여주는 기능이다. 새로운 역할이나 기여·영향 관계는 별도로 입력하고 검토해야 한다.

## 6. 기록의 정확성을 위한 구분

| 구분 | 기록 방식 |
|---|---|
| 실제와 예정 | 실제 기간과 예정 기간을 구분 |
| 진행 상태 | 구상·예정·진행·완료 등을 기록 |
| 관계의 유효 기간 | 역할·지원·협력이 언제부터 언제까지 유효한지 기록 |
| 근거 상태 | 기대·가설, 관찰, 자료로 확인한 내용을 구분 |
| 설명과 출처 | 관계를 판단한 이유와 관련 자료를 연결 |

완료한 활동이라도 목적에 기여했는지는 가설일 수 있다. 활동의 진행 상태와 효과에 대한 근거 상태를 분리한다.

날짜·수량·근거가 아직 없더라도 기록을 시작할 수 있게 한다.

## 7. 기본 사용 흐름

1. **활동과 주체를 펼쳐놓는다.** 주요 활동을 입력하고, 큰 활동과 세부 활동을 묶는다.
2. **참여 역할과 기여를 연결한다.** 누가 무엇을 맡고 어떤 자원을 제공하는지 기록한다.
3. **활동 간 관계를 연결한다.** 경험 제공, 지원, 파생, 자원 공유, 시간 경합 등을 표현한다.
4. **변화와 목적을 연결한다.** 누구에게 어떤 변화가 생기며 왜 중요한지 살펴본다.
5. **필요한 부분의 순환을 분석한다.** 반복되는 성과나 어려움을 변화 요인과 영향 관계로 펼친다.
6. **판단과 후속 질문을 남긴다.** 이어갈 활동, 조정할 역할, 새로 만들 연결, 확인할 가설을 기록한다.

## 8. 초기 개발 방향

처음부터 고려할 구조와 단계적으로 구현할 기능을 구분한다.

| 구분 | 내용 |
|---|---|
| 초기 데이터 구조에 포함 | 주체, 활동, 활동의 포함 관계, 참여 역할, 관계 종류, 기여 종류, 유효 기간, 실제·예정 및 근거 구분 |
| 첫 사용 버전 | 활동·주체 추가, 관계 편집, 시간·협력·목적 보기, 선택 대상의 주변 관계 강조, 저장·불러오기·내보내기 |
| 후속 기능 | 변화 요인과 순환 보기, 영향 방향·지연 표시, 과거 시점 조회, 자동 배치 개선 |
| 별도 검토 | 공동 편집, 외부 데이터 연동, AI 관계 추천, 자동 순환 탐지 |

개인용·조직용 범위, 접근 권한, 저장 방식은 구현 전에 결정한다. 다른 사람의 참여 정보를 기록하는 기능과, 그 사람에게 편집·열람 권한을 주는 기능은 구분한다.

## 9. 설계 원칙

- 한 번 기록하고 여러 관점에서 탐색한다.
- 활동·주체·목적·변화 요인과 관계 종류를 구분한다.
- 큰 활동은 접고 세부 활동은 펼쳐볼 수 있게 한다.
- 성과와 협력뿐 아니라 부담·경합·의존도 함께 살펴본다.
- 개인의 생활·학습·회복을 활동의 기반으로 다룬다.
- 관찰한 사실과 기대·가설을 구분한다.
- 전체 지도와 선택한 대상의 주변 지도를 오갈 수 있게 한다.
- 지도 작성의 완성도보다 실제 판단에 도움이 되는지를 중시한다.
