# action-map

활동 지도 — 활동·협력·목적·순환을 탐색하는 시각적 사고 도구.

- 개발 계획: [docs/DEVELOPMENT_PLAN.md](docs/DEVELOPMENT_PLAN.md)
- 원본 기획자료: [docs/planning/](docs/planning/)

## 개발

```bash
npm install
npm test          # 단위 테스트
npm run test:e2e  # 브라우저 시나리오 테스트 (Playwright)
npm run dev     # 개발 서버
npm run build   # 타입 검사 + 빌드
```
